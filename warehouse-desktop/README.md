# FastGo Склад для Windows

Актуальная версия указана в package.json. Установщик содержит интерфейс склада внутри приложения и открывает его по `fastgo://app/warehouse.html`. Каталог, документы и авторизация приходят с сервера. Изменения экранов устанавливаются новым EXE; работающий документ не заменяется новой веб-страницей.

Программа проверяет свой канал `warehouse/update/latest.yml` при запуске и каждую минуту. Загруженный установщик ждёт завершения документа и освобождения USB. Черновики, количество и способ оплаты сохраняются. Профиль прежней установки переносится без удаления привязки.

Приход, продажа и QR ремонта от ТСД открывают соответствующий экран и восстанавливают свёрнутое окно. Активный ввод и несохранённая форма откладывают переключение. Сервер разрешает работу ТСД ровно для двух настроенных ноутбуков; подключение USB не меняет интернет-привязку к станции.

`ru.fastgo.tsd.app` является отдельным нативным Android-приложением. USB-обновление использует `warehouse/native-update.json`, проверяет SHA-256, ждёт закрытия документов, выполняет `adb install -r` и сверяет версию. При первой установке подключённый ноутбук передаёт независимую сессию через защищённый USB-канал и привязывает ТСД к кассовой станции из первого разрешённого слота. Учётные данные зашифрованы; существующая привязка не заменяется. Android самостоятельно проверяет подпись обновления.

Прежнее `ru.fastgo.tsd` 2.0.0 и его закрытая база остаются отдельно: ключ прежней подписи утрачен, поэтому новая программа устанавливается рядом. Несинхронизированные документы прежней программы автоматически не переносятся. Ключ новой линии обновлений хранится вне репозитория с зашифрованной резервной копией.

Старая оболочка `ru.fastgo.terminal.test` сохраняется отдельно вместе со своими документами.

Закрытие окна оставляет склад в трее для передачи сканов и обновлений. Если установлено общее FastGo, автоматический запуск при входе в Windows принадлежит ему. Полный выход доступен в меню значка.

ТСД 2.1.5 показывает на главном экране «Выдача запчастей». Кассир сканирует детали, затем QR из кнопки «Взять запчасти» в ремонте мастера и нажимает «Выдать». Сервер связывает детали с ремонтом и техникой, списывает остаток один раз. Ручное добавление деталей в ремонт закрыто; ремонт без деталей требует подтверждения мастером «Без замены запчастей».

На карточке товара под штрихкодом доступна печать этикеток: количество, формат и системный выбор принтера. Колокольчик Авито показывает входящие сообщения; владелец один раз подключает свой API-аккаунт в настройках колокольчика. Всплывающие окна по умолчанию разрешены кассовой станции «Драгнир».

Интернет-обновление ТСД загружает подписанный APK этой же программы и ждёт закрытия документов. Android показывает стандартное подтверждение установки. На Android 10 автоматическое открытие после замены может быть запрещено системой; уведомление «FastGo обновлён» возвращает в приложение одним нажатием. Повторная авторизация и подключение USB для последующих обновлений не нужны.
