# Диагностика сети в следующем обновлении FastGo Склад

В верхней панели установленного склада появляется кнопка **Сеть**. Она открывает отдельное локальное окно, которое работает и при недоступности сервера.

- Сигнал Wi-Fi, скорость соединения с точкой доступа, активный сетевой адаптер и ответы локального шлюза.
- Подключения, неудачные подключения и отключения из журнала Windows за последние сутки (до 200 событий). Ручные отключения также попадают в журнал.
- Отдельные небольшие проверки DNS, API FastGo, списка обновлений и доступности самого установщика. Установщик проверяется запросом HEAD; повторного скачивания большого файла нет.
- Фактическая скорость и объём загрузки из обновлятора, время без новых данных и ошибка загрузки.
- Сохранение отчёта JSON в выбранное пользователем место. Пароли, токены, данные ремонтов и подписанные параметры URL в отчёт не включаются. Название Wi-Fi и локальные адреса остаются в локальном отчёте; сервер получает только ограниченные показатели диагностики.

Наблюдение за состоянием подключения и загрузки работает в фоне каждые 10 секунд. Пока обновление скачивается или произошла ошибка обновления, активная проверка выполняется не чаще раза в минуту. В остальное время активную проверку запускает пользователь. Утилита не меняет настройки Windows, не отключает адаптер и не требует администратора.

Слабый сигнал и отсутствие ответа на ping сами по себе не доказывают неисправность адаптера. В результатах сохраняется различие между наблюдением, недоступными измерениями и подтверждённым ответом сервера. Автоматический повтор загрузки остаётся в штатном обновляторе; диагностика не заменяет его.

Подготовка предназначена для следующего обновления кассового склада. Проверочная сборка ветки и черновика PR не публикует релиз и не меняет рабочий канал обновления. Для включения сводки на сервере при выпуске нужно также развернуть обновлённый `device-status.js` функции `fastgo-warehouse`; локальное окно работает независимо от этой сводки.

Исправлена кодировка названия установщика и ярлыка: **FastGo Склад**. `appId` остаётся `ru.fastgo.warehouse`; прежнее внутреннее имя EXE явно закреплено через `executableName`, чтобы сохранённый путь автозапуска не менялся. Проверка CI устанавливает опубликованную старую сборку, обновляет её новым установщиком без указания каталога и сверяет единственную запись установки, русское имя, новый ярлык и сохранность данных.

Установщик также заполняет стандартное поле `InstallLocation` в записи удаления приложения. Оно нужно общему FastGo для поиска уже установленного склада при фоновом обновлении. В старых сборках путь был только в отдельной ветке реестра electron-builder; при проверке обновления учитываются оба расположения.

Проверки: модульные тесты диагностики и разрешений IPC, очистка серверной сводки, браузерный тест интерфейса, чтение адаптеров на Windows CI и запуск готового Windows EXE из сборки. Это не проверка Wi-Fi кассового ноутбука: его измерения появятся после установки и запуска этого обновления на нём.

## Термопринтер и запоминание устройства

В верхнюю панель добавлена кнопка «Принтер», доступная и до входа в учётную запись: список установленных в Windows устройств, размер бумаги, сохранение выбора и пробная этикетка по отдельному нажатию. Общий FastGo и отдельный склад используют один локальный профиль на данном ноутбуке. Для этикеток и листа A4 сохраняются отдельные очереди; настройка принтера ремонтных бланков остаётся отдельной.

Следующая печать сразу направляет задание в сохранённую очередь по её системному имени. Если очередь удалена, приложение просит подключить принтер и обновить список; другую очередь оно самостоятельно не подставляет. Выбор в стандартном диалоге Windows также остаётся доступным. Отмена печати не меняет сохранённое устройство. Пока задание передаётся драйверу, обновление приложения откладывается.

Параметры принтера хранятся в `%APPDATA%/FastGo/printer-profiles.json`, переживают перезапуск и установку новой версии. Передача задания драйверу не доказывает физическую печать. По фотографии определена модель DETONGER P2, пользователь подтвердил подключение к кассовому «Драгниру». Список установленных очередей и сохранённый профиль этикеток передаются в диагностике рабочей станции раз в минуту после обновления. Драйвер Windows и выход реальной этикетки на этом устройстве ещё не подтверждены. Приложение не устанавливает неизвестный драйвер автоматически.
