# FastGo для iPhone

Версия 1.0.1, iOS 16.4 и новее, пакет `ru.fastgo.ios`. Сборка Xcode содержит исполняемый файл arm64 и интерфейс сервиса и склада в каталоге `web` внутри IPA. WKWebView загружает установленные файлы через сервер на `127.0.0.1:17861`; данные и авторизация используют HTTPS API FastGo.

Рабочий процесс `FastGo iPhone` компилирует устройство и симулятор, устанавливает приложение в симулятор, проверяет видимые поля входа и кнопку «Войти», сохраняет DOM-подтверждение и снимок экрана. Успешная компиляция отдельно от этой проверки не считается подтверждением отображения интерфейса.

IPA публикуется без подписи конкретного iPhone. Для установки пользователь подписывает его через Sideloadly или Apple Developer. Автоматическая установка нового IPA без подписи и подтверждений iOS не предусмотрена. Камера, вход и остальные сценарии на физическом iPhone требуют проверки после установки; данные доверенного устройства из Safari автоматически не переносятся.

Новая версия интерфейса поставляется новым IPA. Установленная программа не заменяет свои экраны содержимым размещённого сайта.
