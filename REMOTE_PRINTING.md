# Печать FastGo с телефона на ноутбук

1. На ноутбуке установите Google Chrome и драйвер принтера.
2. Скачайте FastGo-Print-Windows.cmd (Windows) или FastGo-Print-Mac.command (macOS).
3. Запустите файл, выберите 1 — настройка. Войдите в FastGo; вернитесь в окно станции и нажмите «Проверить вход».
4. Нажмите «Тестовый лист / выбор принтера». Выберите физический принтер, формат A4 и нужные параметры. Распечатайте тест. Не выбирайте «Сохранить как PDF».
5. Закройте все окна отдельного профиля FastGo Print. Обычный Chrome закрывать не нужно.
6. Снова запустите файл и выберите 2 — без подтверждения. Отметьте готовность и нажмите «Принимать задания на этом ноутбуке».
7. Оставляйте окно открытым, ноутбук — включённым. Приёмка на телефоне после сохранения и загрузки файлов отправляет лист мастера с QR в очередь.

Для macOS после скачивания может понадобиться разрешить запуск файла:
`chmod +x ~/Downloads/FastGo-Print-Mac.command`, затем открыть его через Finder.
Для Windows настройки и обычная работа используют один отдельный профиль FastGoPrintProfile.
Не открывайте станцию в этом профиле обычным Chrome: запускайте через файл и режим 2.

## Повторная печать и ошибки
Кнопка «Печать» в карточке при активной станции отправляет новый лист на ноутбук.
При отключённой станции она сохраняет прежнюю локальную печать.
Повторное сохранение одной приёмки не создаёт ещё один автоматический лист.
Очередь переживает закрытие ноутбука; после включения продолжает работу.
После необратимого запуска печати задание не повторяется автоматически даже при потере связи.
В очереди можно вручную повторить лист, если вы проверили принтер и бумаги нет.
«Передано на печать» означает вызов браузера; приложение не получает подтверждение физического выхода бумаги.
Если окно печати всё-таки появляется, закройте отдельный профиль и снова запустите режим 2.

## Реализация
Служебные таблицы доступны только сервисной роли; внешний API проверяет действующую сессию и активный доступ к мастерской.
Назначение станции — владелец или администратор; получает задания только назначенное устройство под назначенной учётной записью.
Резервирование атомарное, до запуска действует аренда 3 минуты.
После отметки dispatched автоматический повтор запрещён.
Используется штатный флаг Chrome --kiosk-printing:
https://github.com/chromium/chromium/blob/main/chrome/common/chrome_switches.h
