на новую базу в 16:18 по Оренбургу. Повторно выполнять установку сейчас не нужно.
Ниже сохранена исходная инструкция для справки.

1. Открой существующий проект:
   https://script.google.com/home/projects/1veLA4VEcDWNzsxlr51E4VdES-fpDy7dbiO12apikOIcKo7bKMm0KphPh/edit
2. Слева рядом с «Файлы» нажми «+» → «Скрипт». Назови файл `NativeSync`.
3. Замени его содержимое кодом из `google-apps-script/NativeSync.gs` и сохрани.
4. В списке функций сверху выбери `installNativeSync` и нажми «Выполнить».
