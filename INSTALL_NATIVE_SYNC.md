# Подключение фоновой синхронизации FastGo

Этот шаг нужен из-за недоступности облачного браузера. Серверная часть подготовлена,
но рабочее приложение пока не переключено на новое хранилище.

1. Открой существующий проект:
   https://script.google.com/home/projects/1veLA4VEcDWNzsxlr51E4VdES-fpDy7dbiO12apikOIcKo7bKMm0KphPh/edit
2. Слева рядом с «Файлы» нажми «+» → «Скрипт». Назови файл `NativeSync`.
3. Замени его содержимое кодом из `google-apps-script/NativeSync.gs` и сохрани.
4. В списке функций сверху выбери `installNativeSync` и нажми «Выполнить».

Успешный результат в журнале: «Синхронизация подключена. Снимок совпадает.»
После этого сообщи результат — я проверю передачу данных и выполню переключение.
Существующие файлы «Код» и «Reliability», развёртывания и пароли менять не нужно.
Если появится сообщение об отличии снимка, остановись и передай его: перед
переключением нужно сверить свежие изменения в таблице.
