# Редактирование данных FastGo Service — 6 ноября 2026

Общий маршрут используется сайтом, мобильным APK и приложением Windows. Состав полей взят из существующих карточек и схемы, новые ID не создаются.

| Данные | Видимая точка входа | Кто / ограничение | Сохранение |
|---|---|---|---|
| ФИО, телефон, email клиента в ремонте | «Изменить клиента» на экране техники | Приёмщик, менеджер, администратор, владелец; у закрытого ремонта нужна причина и административное право | Версия ремонта, аудит; сохраняется ID клиента |
| Клиент в общем списке | «Изменить» в строке клиента | Те же роли; меняется карточка клиента, завершённые приёмки сохраняют свой снимок | Сверка исходных ФИО/телефона/email, аудит, защита от дублирующего телефона |
| Бренд/модель, серийный номер, комплектность, состояние, обращение, план готовности | «Изменить технику и приёмку» | Приёмщик/менеджер/администратор/владелец; выбор техники из существующего каталога | Версия ремонта, аудит |
| Диагностика, план готовности, служебное примечание | «Изменить диагностику» | Сотрудники сервисной очереди; закрытая карточка — административная корректировка с причиной | Версия ремонта, аудит |
| Название, количество и стоимость работы; своя работа | «Изменить» у строки и «Добавить свою работу» | Сотрудники сервиса; общий прайс этим не меняется | Проверенные строки, существующая транзакция ремонта; завершённые работы — корректировка акта |
| Ожидаемая деталь и дата | «Изменить ожидание» в запчастях | Сотрудники сервиса, открытый ремонт | Существующая операция ожидания запчастей |
| Уже выданные детали | «Исправить выдачу / вернуть деталь» | Кассовые сотрудники; обязательная причина; мастер не вводит складские позиции вручную | Существующее обратное движение склада, версия и аудит; выдача новых — ТСД/АТОЛ |
| Скидка, итог, согласование | «Изменить расчёт» | Приёмщик/менеджер/администратор/владелец; ниже оплаченного — сначала возврат | Существующий расчёт, фиксированные оплаченные суммы сохраняются |
| Гарантия и примечание о выдаче | «Изменить данные выдачи» | Приёмщик/менеджер/администратор/владелец; закрытый ремонт — с причиной | Версия ремонта и аудит; дата фактической выдачи вычисляется системой |
| Текст акта, названия и цены строк завершённого ремонта | «Исправить акт» | Существующие права корректировки акта; причина обязательна | `repair_act_save`, сохранение происхождения складских строк и платежей |
| Фото и видео | «Фото и видео» / загрузка | Существующие права и приватное хранилище | Существующая загрузка; история файлов сохраняется |
| Проведённые платежи и складские движения | Переход в операции кассы | Существующие кассовые права и разрешённые рабочие места | Только корректирующая операция/возврат, без перезаписи журнала |
| Системные ID, номера, история, авторы, время платежа/движения | Просмотр | Рассчитываются системой | Прямого редактора нет |

Каждое изменение использует код операции для безопасного повтора и проверку версии. При конфликте ввод остаётся в форме; актуальную карточку открывают отдельно для сверки. Тесты выполняются на изолированных данных.
