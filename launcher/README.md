# FastGo Склад — лаунчер 1.0.2

Один переносимый EXE для Windows 10/11. Использует встроенный .NET Framework 4.6 или новее; Electron и отдельный установщик лаунчера не нужны.

Откройте `FastGo-Warehouse-Launcher.exe`, нажмите «Скачать обновление» и дождитесь проверки SHA-512. После завершения работы в FastGo Склад, включая значок в трее, нажмите «Установить». Откроется обычный мастер установки склада. Текущую работу приложение принудительно не закрывает.

«Подключить термопринтер P2» настраивает DETONGER P2 на том компьютере, где открыт лаунчер. Включите принтер и подключите его по USB к кассовому ноутбуку, затем нажмите кнопку. Если очередь уже существует, повторной установки нет. Если драйвер отсутствует, скачивается официальный драйвер 3.2.2026.1018; SHA-256 и цифровая подпись проверяются до запроса прав Windows. Лаунчер использует общую со складом блокировку установки и запись результата в `%APPDATA%\FastGo\printer-setup\p2`, поэтому установку не запускают две программы одновременно.

Наличие драйвера без очереди принтера отображается отдельно и не считается готовой печатью. После регистрации P2 откройте в FastGo «Принтер», выберите P2 и размер своего рулона, затем нажмите «Пробная этикетка». Проверки программы не подтверждают выход бумаги и читаемость штрихкода на реальном устройстве.

Загрузка поддерживает продолжение после обрыва, три попытки соединения и отмену с сохранением части файла. Показывает размер, скорость и прогресс. Контрольная сумма и размер берутся из официального HTTPS-канала склада. Переходы разрешены только на серверы GitHub. Повреждённый файл не становится готовым установщиком. Понижение установленной версии заблокировано.

«Проверить сеть» проверяет сетевое подключение Windows, DNS, порт 443, HTTPS-канал обновлений, доступность Windows-установщика, место на диске и системный прокси. «Сохранить отчёт» создаёт текстовый отчёт. Проверка доступности не является измерением скорости интернета; скорость отображается по полной загрузке.

«Убрать окна JARVIS» применяет исправление фонового запуска `JARVIS_Bybit_Telemetry` и существующего автозапуска JARVIS. Оно встроено в EXE и работает без отдельного скачивания. На кассовом ноутбуке автоматически определяется существующая установка бота; сохраняются расписание задачи и резервная копия в `.quiet-launch-backup` внутри папки бота. Работающий бот не перезапускается. Уже открытое старое консольное окно не закрывается автоматически. Если для изменения задачи не хватает прав, Windows предложит повышение прав; при отказе показывается понятный результат. Причина ошибки и её код доступны прямо в окне и в сохраняемом отчёте. При отсутствии JARVIS изменения не выполняются.

В 1.0.1 исправлен разбор задач `cmd.exe`/`wscript.exe`, который в 1.0.0 мог склеить путь Windows с путём бота. Добавлены проверки автоматического обнаружения, UTF-8 передача ошибок из скрытого PowerShell, распознавание стандартного NSIS-имени склада с версией и защита от повторного запуска открытого установщика. Версия Electron из EXE не принимается за версию склада.

Файлы загрузок, диагностические журналы и копия встроенного исправления находятся в `%LOCALAPPDATA%\FastGo Launcher`. Данные склада и его настройки хранятся самим складом.

## Сборка и проверка

```powershell
./launcher/build.ps1
./launcher/dist/Launcher.Tests.exe
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./launcher/repair/Tests.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./launcher/repair/Transport.Tests.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./launcher/repair/Printer.Tests.ps1
./launcher/dist/FastGo-Warehouse-Launcher.exe --check
./launcher/dist/FastGo-Warehouse-Launcher.exe --diagnose
./launcher/dist/FastGo-Warehouse-Launcher.exe --download ./verification/installer
./launcher/dist/FastGo-Warehouse-Launcher.exe --ui-smoke ./verification
./launcher/dist/FastGo-Warehouse-Launcher.exe --printer-inspect
```

`--download` только загружает и проверяет файл; установщик не запускается. `--jarvis-inspect` только проверяет наличие бота, без применения исправления. `--printer-inspect` только проверяет Windows и не устанавливает драйвер. Проверки P2 используют временную папку и подменённые операции принтера/установщика, без установки реального драйвера и без отправки печати. Проверки JARVIS используют временную папку и подменённый планировщик; торговый бот и настоящие задачи не запускаются. Подтверждение работы на физическом кассовом ноутбуке выполняется отдельно.
